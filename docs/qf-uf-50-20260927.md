| --- | ---: |
| `eq-symm` | 11,716 |
| `bool-double-not-elim` | 7,697 |

The isolated checks preserve the translated declarations and RARE steps, remove
the original assumptions and other proof steps, and run Ethos on each resulting
file. All extracted RARE instances are premise-free, and the extracted counts
match the source certificates. These checks validate the rewrite instances;
they are not complete refutations.

**There are zero `rare-list` arguments and zero `distinct-false` instances in
this sample.** This batch therefore adds no direct coverage of the empty-list,
singleton, or `distinct` representation fix. Its focused validation remains the
[separate distinct fuzz run](rare-list-distinct.md).
